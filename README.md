#  SRS TETRION

A web-based Tetrion game featuring standard SRS rotation rules and PeerJS-powered P2P multiplayer.
🔗 [**Play Game Now (Live Link)**]https://kwon0114.github.io/Tetrion/

<br />

## 🔥 Key Features
- **Precise Tetrion Logic:** Implements standard SRS rotation, Wall Kicks, and 180° spins.
- **Handling Customization:** Allows players to fine-tune DAS, ARR, and Soft Drop speeds in milliseconds.
- **PeerJS-Powered P2P Multiplayer:** Enables low-latency 1v1 battles via direct browser-to-browser connections without a dedicated game server.
- **Multiple Game Modes:** Supports Single Player (Normal, Blitz, PC Streak), Local 2P, and Online Matchmaking.

<br />

## 🛠 Tech Stack
- **Frontend:** HTML5 Canvas, CSS3, JavaScript
- **Networking:** PeerJS (WebRTC)
- **Deployment:** GitHub Pages
